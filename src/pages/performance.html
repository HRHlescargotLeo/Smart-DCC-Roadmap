What we're proposing

The same four performance measures and the same headline statistics, drawn from data rather than pasted in as pictures. Every chart can be read month by month, switched to a table and downloaded as a CSV, and the whole set downloads in one file.

Why

The four charts on the Performance page are PNG images. Their alt text names each chart but gives no values, so a screen reader user learns that a chart exists and nothing else. Nobody can reuse the figures without retyping them. The mobile and desktop versions are separate images, and they don't quite agree: October's top-up figure is 97.4% in one and 97.5% in the other.

All figures on this page are live, read from smartdcc.co.uk on 28 September 2026.
