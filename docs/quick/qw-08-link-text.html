Quick win 8 of 21 · Small fixes that add up

Links that say where they go

Four onboarding steps link the word "here". Name the destination instead.

Now

  1. If you're an energy supplier or network operator… you'll need to become party to the Smart Energy Code. You can find out how here.
  2. …you'll need a DCC User Gateway Connection. You can order one from here.
  3. All the steps you need to follow… are right here in the SMKI RAPP.
  4. Find out more about the tests here.
  • here
  • here
  • here
  • here

With this change

  1. If you're an energy supplier or network operator, you'll need to become a party to the Smart Energy Code.
  2. You'll need a DCC User Gateway Connection. Order one through the Customer Service Centre.
  3. Follow the steps in the SMKI Registration Authority Policies and Procedures (RAPP).
  4. Read about the SMKI and Repository Entry Process Tests.
  • become a party to the Smart Energy Code
  • Order one through the Customer Service Centre
  • SMKI Registration Authority Policies and Procedures (RAPP)
  • SMKI and Repository Entry Process Tests
