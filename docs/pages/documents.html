Prototype 3 of 5 · Document Centre

What we're proposing

A Document Centre you can narrow down: filters for category, regulatory year, programme and file type that can be combined, a count of what's left, a clear "current" badge, earlier versions tucked under each document, and superseded documents hidden unless asked for.

Why

There are 1,494 documents across 166 pages. The only way to narrow them is a single category dropdown and an archive checkbox, so finding last year's charging statement means paging back through everything published since. Some documents show "Version: 2" and most show nothing, which leaves the reader to guess whether they have the latest.

The first nine documents are the live first page. The rest are sample entries using real categories and naming. Ten per page here so the paging shows; we'd suggest 25 on the live site.

BehaviourFilters apply as soon as they're ticked and can be combined. Counts beside each option show current documents. On a phone the filters sit behind a single button, so the first document is on the first screen rather than below the search, dropdowns and archive checkbox as it is now.

    VersionsEach document is one record with a version history, so publishing version 3 replaces version 2 in the list and moves it underneath. Try "Information Security Policy".

    Open questionRegulatory year and programme aren't tagged on documents today. Tagging 1,494 documents is a real piece of work; we'd suggest tagging everything from RY 2024/25 onward and leaving older ones to category and date.
